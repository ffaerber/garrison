# Platform

The repo `system/platform`: public contracts other repos may rely on and the hostnames root reserves. It has no `compose.yaml`, so the controller does not deploy it.

Every other repo of the `system` organisation is one system stack; see `docs/spec.md`, "System stack".

Dashboards live in the repos they belong to, as `dashboards/*.json`; see `system/grafana/dashboards/README.md`.
