# What this page looks for

The agents read this file before each update: each topic below, in plain
words, with the sites to look at first. Change it whenever you like; a
change starts an update at once.

A topic may also say where its items must come from, in a line like
"Only from: kubernetes.io, github.com" (subdomains included). The page's
tests then refuse any other link for it, even one a web page asked the
agents to add.
