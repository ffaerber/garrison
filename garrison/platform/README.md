# Platform

The repo `garrison/platform`: public contracts other repos may rely on and the hostnames root reserves. It has no `compose.yaml`, so the deployer does not deploy it.

Every other repo of the `garrison` organisation is one system stack; see `docs/spec.md`, "System stack".

Dashboards live in the repos they belong to, as `dashboards/*.json`; see `garrison/grafana/dashboards/README.md`.
