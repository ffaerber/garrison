    Models

    The LLM providers Garrison's agents use: OpenAI-compatible APIs, in llm/providers.yaml of garrison's config. Their models are listed by themselves: soon after a provider is added, and once a day, Garrison asks each for its models and proposes them in llm/models.yaml, turned off; enable there those agents may use. A provider's API key is encrypted as you save it, and nobody can read it back, here or in Git.

    Secrets

    Keys, passwords and tokens for a unit's apps. A value is encrypted as you save it, and nobody can read it back, here or in Git: it can only be replaced. An app's main environment gets each secret its stack file names under secrets:, as the file /run/secrets/<name>; its other environments get values of their own, so code not yet merged never sees one.
